# YTÜ Programming Languages 1 (C) Coursework

This repository contains weekly coursework, algorithm implementations, laboratory exercises, and study notes for the **Programming Languages 1** course at Yıldız Technical University.

## 📂 Repository Structure
- `week1-3 variables and data types/`: Fundamentals, primitive types, and variable assignments.
- `week4 scanf&operators/`: Standard I/O, arithmetic, logical, and bitwise operations.
- `week5 decision/`: Conditional control flow (`if-else`, `switch-case`).
- `week6 loops/`: Iteration structures (`for`, `while`, `do-while`).

## 🛠️ Environment & Tools
- **Language:** C (C99 standard)
- **IDE / Compiler:** Dev-C++ / GCC (MinGW)
- **File Types:** `.cpp` (source code), `.pdf` & `.png` (lecture annotations & board notes)
